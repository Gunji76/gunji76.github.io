yt-pull プライバシーポリシー

最終更新: 2026-09-23

何をするツールか

yt-pull は、開発者本人が所有する YouTube チャンネルの分析数値を取得して手元の Mac に保存する 個人用のコマンドラインツールです。利用者は開発者本人だけで、第三者に配布していません。

取得するデータ

  • YouTube Analytics API: 視聴回数、総再生時間、平均視聴時間、視聴維持率、流入元、検索語句、 高評価数、チャンネル登録者の増減
  • YouTube Data API: 動画の公開統計(視聴回数・高評価数・コメント数)、動画の長さ、 動画の説明文・サムネイル・再生リストの更新

対象はすべて開発者本人のチャンネルの動画です。他のユーザーのデータは取得しません。

データの保存と共有

取得した数値は開発者の Mac のローカルディスクにのみ保存します。外部のサーバーへ送信しません。 第三者への提供・販売はしません。認証情報(OAuth トークン)も同じ Mac のローカルにのみ保存します。

データの削除

保存したデータと認証情報はローカルのファイルを削除することでいつでも消せます。 Google アカウントのアクセス権は Google アカウントの「サードパーティ製のアプリとサービス」 から取り消せます。

Google API サービスの利用

本ツールは Google API から受け取った情報の利用について、 Google API Services User Data Policy (Limited Use の要件を含む)に従います。
